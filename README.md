# Pranav Desai - Backend & Systems Engineer Portfolio

> A minimal, high-performance, terminal-inspired portfolio built to showcase low-level systems, data pipelines, and backend architectures.

## Overview
This repository contains the source code for my professional portfolio. Unlike traditional frontend-heavy portfolios, this site is designed with a strict "backend engineer" aesthetic—favoring stark contrasts, `JetBrains Mono` typography, and comprehensive technical case studies over flashy animations.

## System Architecture (The Portfolio Itself)
The portfolio is built as a single-page application using **Svelte** and styled with pure, dependency-free CSS to maximize performance and minimize bundle size.

- **Framework:** Svelte (Vite)
- **Routing:** Custom state-driven dynamic sidebar navigation (`store.svelte.js` + `navigation.js`)
- **Styling:** Vanilla CSS using CSS Variables for a centralized dark-mode color token system. No Tailwind or Bootstrap.
- **Typography:** JetBrains Mono for a complete IDE/Terminal feel.

## Key Features
- **Dynamic File-Based Routing:** The sidebar navigation is automatically generated by scanning the `src/pages` directory using Vite's `import.meta.glob`, allowing for immediate documentation generation.
- **Technical Case Studies:** Project pages act as system specification documents, explicitly outlining the "Why" behind architectural decisions, memory management, and scaling trade-offs.
- **Zero-Layout-Shift Hero:** Highly optimized CSS structure prevents layout shifts during load.

## Local Setup

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
# Clone the repository
git clone https://github.com/PranavDesai-Git/portfolio.git
cd portfolio/svelte-app

# Install dependencies
npm install

# Run the development server
npm run dev
```
